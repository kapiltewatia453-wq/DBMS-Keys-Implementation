**BCA Data Science - Final Year Project by Kalpana**

## What is this Project?
This project shows how DBMS Keys work in a real database using Python + SQLite, and how to analyse that data using Pandas.

## Keys Used
- Primary Key: roll_no
- Unique Key: email
- Foreign Key: roll_no in marks table
- Composite Key: roll_no + subject
